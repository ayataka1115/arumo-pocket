# アルノポケット（ARuMo Pocket）

家の中の冷蔵庫・冷凍庫・食品棚・日用品・くすり箱など、あらゆる棚の「ある・ない」を
**写真1枚**で家族と共有するモバイル Web アプリ（PWA）。

> 家の「ある・ない」を撮って共有。買い物のお願いまで、ひとつのポケットに。

旧称「ウチの冷蔵庫」。冷蔵庫だけのアプリを、家中の棚に広げたもの。

---

## 中身

```
index.html                画面の骨組み
css/tokens.css            色・角丸・影・余白・書体・動き（値はここ1か所）
css/app.css               画面の組み立て
js/data.js                保存・棚・キャラ・品目モデル・期限・不足判定
js/sync.js                家族との差分同期、Gemini への取り次ぎ、画像の縮小
js/ui.js                  画面を描く（ホーム/棚/買うもの/ことづて/レシピ/分析）
js/app.js                 触ったときに起きること、設定、書き出し、通知
assets/                   ロゴ2・棚アイコン24・キャラ20・装飾3（すべて SVG）
gas/Code.gs               共有バックエンド（同期 + Gemini 取り次ぎ）
gas/appsscript.json       Web App のデプロイ設定
公開用/                   そのまま配信できる一式（Netlify Drop 等へ）
_backup_20260822/         「ウチの冷蔵庫」時点の控え
```

ビルド不要。素の HTML / CSS / JS。`公開用/` をそのまま静的ホスティングに置けば動く。

## 実装済みの機能

| # | 機能 | 状態 |
|---|---|---|
| A | 目標数（下回ると「不足」） | 済。個数は `target`、残量は `stockTarget`。棚バッジ・不足タブ・ホームの「気になる子たち」に出る |
| B | 変更履歴（誰がいつ変えた） | 済。品目ごとに最新20件。カードの時計アイコンから見る |
| C | 家族チャット / スタンプ | 済。同期に `kind:'chat'` として乗る。スタンプ4種 |
| D | 棚べつ通知 ON/OFF | 済（アプリを開いたとき1日1回。時間帯は朝／いつでも／夕方） |
| E | レシート OCR | 済。読み取った品目で買い物リストを消し、棚にも入れる |
| F | 消費パターン学習 | **未着手（今回の対象外）** |
| G | AI レシピ提案 | 済。期限が近いものを優先。買い足すものを買い物リストへ送れる |
| H | ホーム画面（PWA） | 済。manifest + Service Worker（圏外でも開ける） |
| I | CSV エクスポート | 済。棚の中身／これまでの記録／まるごと JSON の3種 |
| J | 統計・棚べつ分析 | 済 |

D の注意：**アプリを閉じている間には鳴らない。** バックグラウンド通知には Push 配信サーバ
（と iOS では Web Push の購読）が要るため、そこには踏み込んでいない。

## 使いはじめ

### 1. 手元で見る

```bash
node /private/tmp/claude-501/-Users-macbook-Desktop-Claude-Code/7507196f-f975-4d23-9d82-f0e8fc73aa2e/scratchpad/serve.mjs "$PWD" 5179
```

`.claude/launch.json` の `arumo-pocket` からも起動できる。
同じ Wi-Fi なら iPhone から `http://<MacのIP>:5179` で実機確認できる（公開不要）。

### 2. 家族と共有する（GAS）

1. Google スプレッドシートを新規作成 → **拡張機能 > Apps Script**
   （※ スプレッドシートから作らないと `getActive()` が null になる）
2. `gas/Code.gs` と `gas/appsscript.json` を貼る
3. **プロジェクトの設定 > スクリプト プロパティ** に `GEMINI_API_KEY` を入れる
   （<https://aistudio.google.com/apikey> で取得）
   `GEMINI_MODEL` は省略可。省略すると `Code.gs` の `GEMINI_MODELS` を
   頭のいい順に試す（落ちたモデルは休ませて、次の候補へ下りる）
4. **デプロイ > 新しいデプロイ > ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（"Google アカウントを持つ全員" では弾かれる）
5. `/exec` の URL をアプリの **設定 > 共有** に貼り、「新しく作る」で家族コードを作る
6. 家族の端末にも同じ URL と家族コードを入れる

写真の読み取り（E）とレシピ（G）も、この URL 経由で Gemini に取り次ぐ。
**API キーは端末に置かない。**

## 同期のしくみ

- 操作はまず手元に保存し、通信は後追い。圏外でも普通に使える
- 変更したレコードに `dirty` 印が付き、つながったときにまとめて送る
- 削除は行を消さず `deleted` 印を立てる（消したことを家族に伝えるため）
- ぶつかったら `updatedAt` が新しいほうを採る（後勝ち）
- 「前回の続き」の目印は**サーバー時刻**（`srv`）。端末の時計がずれても取りこぼさない
- **送った変更は、サーバーが弾いたぶんも必ず返す**。返さないと圏外で編集した端末だけずれ続ける
- 棚・数え方・目標数・履歴は `ext` 列に JSON でまとめる。表の列を増やさずに機能を足せる
- `Content-Type` ヘッダは付けない。付けると事前確認（preflight）が飛んで GAS が答えられない

### シート

- `data` … レコード本体（1レコード=1行）
- `houses` … 一度でも同期しに来た家の台帳。自動で作られる。
  AI を使う action は、ここに載っている家だけ通す。
  **品目が0件でも載る**（棚が空の端末が、写真の読み取りを使えないと困るため）

### 検証

デプロイせずに同期ロジックを確かめられる：

```bash
node tools/gas-harness.mjs gas/Code.gs   # サーバー側だけ（家族コードの検査・回数の上限・モデルの切り替え）
node tools/flow-harness.mjs              # 端末側と通し（js/sync.js と gas/Code.gs を fetch でつなぐ）
```

## デザインの約束（AI slop を避けるための線引き）

- パステル面に**白文字を載せない**。濃い同系色（`-deep`）を載せる
- カード左の色帯は貼らない。上端 6px のストライプか右上バッジで示す
- 純黒の影は使わない。オリーブ寄りグレー
- 絵文字は使わない（OS で表情が変わるため）。表情は `assets/` のキャラ SVG に任せる
- 書体は Zen Maru Gothic（見出しは Fraunces、数字は DM Mono）
- コピーは**食材が話す**（「牛乳、あと少しだよ〜」）。1画面1メッセージ。短い UI コピーに句点は付けない
- 誰かを名指ししない（「おかえりママ」ではなく「ただいま、〇〇家」）

値はすべて `css/tokens.css` の `:root`。**色を変えたいときはそこ1か所**を触る。
